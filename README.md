# 王家の遺伝子（myKingdom）

遺伝子を持つ人間の王侯貴族が、恋をし（魅力）、縁談を結び（結婚と同盟）、子を残し、王位を継ぎ、戦争と反乱で国を奪い合う——その年代記を眺めて遊ぶ王朝シミュレーションです。
[孤島の遺伝子（isolated-sim）](https://github.com/cfkazu/isolated-sim) の遺伝エンジン（染色体・減数分裂・組換え・血縁係数）を人間向けに作り替えています。

ブラウザだけで動きます（依存ライブラリなし）。1 ステップ = 1 年。

## 遊び方

```sh
npm start            # = python3 -m http.server 8000
# → http://localhost:8000 を開く
```

ES モジュールを使っているので、`index.html` を直接開くのではなく、ローカルサーバー経由で開いてください。サーバーなしで開ける 1 ファイル版は `node tools/build.js` で `dist/myKingdom.html` にできます。


### 家を選んで遊ぶ

はじめに遊ぶ家を選びます（王家か、諸侯の家。「眺めるだけ」もできます）。その家の当主があなたで、当主が亡くなれば跡継ぎが引き継ぎ、家が絶えればおしまいです。決断のときは時間が止まり、カードが出ます。

- **💍 縁談**：当主と当主の子の結婚相手を、相手の家が受けてくれそうな候補から選ぶ。肖像・魅力・家格・同盟・血縁と、**生まれる子の遺伝病の確率**（減数分裂のシミュレーション）を見比べる。平民の出の相手を迎える・見送ることもできる。
- **📚 教育**：当主の子が 6 歳になったら、武芸・学問・社交・信仰から選ぶ。生まれ持った遺伝子に育ちが上乗せされる。
- **🏰 恩賞**（王のとき）：王領が多すぎたら、どの家に土地を与えるかを選ぶ（騎士を取り立てる・手放さないも）。
- **🗡️ 派閥の誘い**（諸侯のとき）：不満な諸侯の派閥に加わるかを選ぶ。
- **📜 出来事**（あなたの家に起きる）：🩸 血友病の跡継ぎ（そのまま／弟を立てる／修道院へ）、🌀 狂気の兆し（幽閉／名医／放っておく）、🗡️ 野心的な身内（問いただす／国外へ追放／放っておくと暗殺も）、🤝 不満な諸侯（土地を与える／縁組／脅す）、👂 不義の子の噂（子の髪と瞳が両親から生まれうるかを遺伝で判定した手がかりつき。実際に不義の子が生まれることもある）、🕯️ 当主の最期（跡継ぎに政・武の心得か、家の誇りを遺す）。継承から外した人・幽閉した人・修道院に入れた人は、継承と縁談から外れる。
- 王国タブから自分で動ける：王なら**宣戦・継承戦争**（兵力の比つき）と**没収**、諸侯なら**王位を奪う反乱・独立の反乱**（勝ち目の目安つき）。

- **▶ 再生 / スペースキー**で時間が進みます。「+1年」「+10年」で少しずつ進めることもできます。
- 地図の地方をクリックすると、その王国の君主・継承順位・歴代の王・戦争が見られます。地図には王侯貴族が一人ずつ点で暮らしていて（当主の一家は居城に、きょうだいやいとこの一家は家のほかの所領に住む。小さな灰色の点は領民で、人口の目安。各伯爵領には持ち主の旗の立つ城がある）（金の縁は王族、白い縁は家の当主、点の中の白丸は女性）、嫁いだ人は新しい宮廷へ旅をし、誕生・結婚・死・即位・会戦はその場所にアイコンが浮かびます。戦争中は軍旗が戦場へ進みます。点をクリックするとその人を見られます。地図の下には選んだ王国の宮廷（王・王妃・王子女の肖像）が並びます。地図の塗り分けは「王国」「王朝」「かつての国（出自）」「人口」「戦禍」から選べます。
- 年代記の人名をクリックすると、その人の**遺伝子どおりに描かれた肖像**（髪・瞳・肌の色、受け口の顎、年齢、王冠）・能力・家族・遺伝子型が見られます。
- 「📌 縁談の相手として固定」してから異性を選ぶと、ふたりの**血縁の近さ・お互いの家からの評価・子の予測**（血友病・受け口・狂気・死産の確率、髪と瞳の色の分布）が出ます（減数分裂を 1500 回シミュレーション）。
- 人物タブや家タブの「📌 〇〇家を追う」で、一つの家を追いかけられます。当主が亡くなると次の当主に自動で切り替わり、年代記は「追っている家」の出来事に絞られます。君主を選んだときも、その王位を追いかけて次の君主に切り替わります。
- 「家系図」タブでは曾祖父母までさかのぼれます。何度も現れる祖先（近親婚のしるし）は同じ色の枠で示されます。
- 「家」タブで家格・存命の人数・出した君主の数と、家ごとの遺伝の傾向（血友病の保因者・受け口・狂気の素質）が見られます。
- 「統計」タブで、領土の推移・貴族の人数・近交係数・遺伝病の遺伝子頻度・能力の平均の推移が見られます。
- 神の介入：🦠 疫病、⚔️ 戦乱の時代、🕊️ 平和の時代（それぞれ 20 年）、🩸 血友病の保因者である美しい亡命貴族の娘を最強国の宮廷に送り込む（ヴィクトリア女王の子孫のように、血友病が王家に広まるか？）。
- 「設定」でシード・王国の数・地方の数・継承法・近親婚への考え・戦争の起こりやすさ・疫病を変えて、新しい世界を始められます。同じシードと設定なら同じ歴史になります。

## 遺伝のしくみ

3 対の常染色体 + 性染色体（XX / XY）に 41 の遺伝子座があり、位置（cM）にもとづいて減数分裂で交叉が起きます。

| 遺伝子 | 遺伝形式 | 効き方 |
|---|---|---|
| 髪の色 | 複対立遺伝子（黒 D ＞ 金 L ＞ 赤 r） | 見た目。北の国ほど金髪が多い |
| 瞳の色 | 複対立遺伝子（茶 B ＞ 緑 g ＞ 青 u） | 見た目。北の国ほど青い瞳が多い |
| 身長 ×4・武勇 ×3・知略 ×4・容姿 ×4・カリスマ ×3・野心 ×2・慈愛 ×2・多産 ×2・長寿 ×2・肌 ×3 | 量的形質（ポリジーン）＋育ちのばらつき | 魅力・指揮・統治・結婚・寿命・戦争の起こしやすさ |
| 免疫型（HLA） | 超優性 | 違う型を 2 つ持つ人ほど疫病に強い |
| 血友病 | 伴性（X 連鎖劣性） | 男性は若死にしやすく、戦に出られない。母が保因者だと息子の半分が発症 |
| 色覚 | 伴性（X 連鎖劣性） | なし（中立） |
| 受け口の顎 | 常染色体劣性 | 容姿が大きく下がる（ハプスブルク家の顎のように） |
| 狂気 | 常染色体劣性 | 大人になってから発症。統治が乱れ、戦争を起こしやすく、国が弱る |
| 有害因子 ×4 | 常染色体劣性 | 虚弱：死にやすく、子ができにくい（近交弱勢） |
| 致死因子 | 常染色体劣性 | 死産 |

近親婚そのものに罰はありません。子が弱るのは、劣性の遺伝子がそろったときだけです（近交弱勢は遺伝子型から生じる）。

## 封建制と地図の階層

- 大陸は **伯爵領**（地方ひとつ）に分かれ、隣り合う 3〜5 の伯爵領が **公爵領**、いくつもの公爵領が **王国** になります。地図の「👑 王国」「🛡️ 公爵領」「🏰 伯爵領」で階層を切り替えられ、「ほかの地図」から諸侯の忠誠・遺伝病（発症者は赤、血友病の保因者は紫で一人ずつ塗り分け）・王朝・出自・人口・戦禍も見られます。
- 伯爵領は王の直轄地（**王領**）か、諸侯の家の所領です。家の所領は当主が治め、家が絶えれば王領に戻ります。公爵領の過半を持つ家は **〇〇公** になります。家の人々はそれぞれの居城に住むので、地図のあちこちに人がいます。
- 王が直轄できる王領には上限があり（統治の力しだい）、余った土地や戦で奪った土地は **恩賞** として諸侯に与えられます（手柄を立てた指揮官の家、土地のない家、同じ公爵領に土地を持つ家が選ばれやすい。騎士が取り立てられて新しい伯爵家になることも）。野心的で冷酷な王は、不満な家から土地を **没収** します。
- 諸侯の当主は王への **忠誠** を持ちます（王との血縁・王家との婚姻・王のカリスマと統治・恩賞の記憶で上がり、当主の野心・狂王・摂政・敗戦・没収や処刑の記憶・大きすぎる所領・滅んだ国の民であることで下がる）。王国タブで内訳が見られます。忠誠の低い家は兵を出し渋ります。
- 不満な家は **派閥**（擁立派・簒奪派・独立派）をつくり、兵力が王に迫ると反乱を起こします。勝てば新しい王朝や新しい国が生まれ、負ければ盟主の家は所領を没収されます。
- 王朝は長く続きやすくなっています：長く続いた王家ほど、王位を奪う反乱（簒奪・擁立）は起きにくい（正統性。独立の動きには効かない）／女王の子や、格下の家に嫁いだ王女の子は王家の名を継ぐ／選挙ではいまの王家の者が選ばれやすい／王の近親の夫婦は貴族の人数の上限にしばられず子だくさん（いとこが増え、近親婚と跡継ぎが生まれやすい）。
- 大きすぎる国にはブレーキがかかります：首都から遠い土地は兵が集まりにくく忠誠も下がる／反乱軍は自分の土地で戦い、不満な諸侯は鎮圧に兵を出さず、ほかの不満な家も反乱に加わる／大国の王が死ぬと王子や王弟が王位を主張する／大陸の 3 分の 1 を超える国が攻めてくると諸国が包囲網をつくる。

## 社会のしくみ

- **魅力** ＝ 容姿・カリスマ・健康・若さ。毎年、独身の人の一部が縁談の市場に出て、お互いの家から見た値打ち（魅力・家格・王族かどうか・同盟の役に立つか・年齢・血縁）の低い方が高い組から結婚します。王族ほど家格と同盟を、そうでない人ほど魅力を重く見ます。相手のいない貴族は平民の出の相手を迎え、新しい遺伝子が入ってきます。
- **近親婚への考え**は国ごとに違います：「近親婚を禁じる」「いとこ婚まで」「血の純潔を尊ぶ」（一族どうしの結婚を好み、叔父と姪まで許す）。
- **同盟**：王家の近親どうしが国をまたいで結婚すると、夫婦が生きている間、同盟が結ばれます。
- **継承法**：男系長子相続・男子優先長子相続・絶対長子相続・選挙君主制。継承者がすでに他国の君主なら**同君連合**で国が 1 つになることがあり、拒まれた人は**請求権**を持って**継承戦争**を起こします。女王の子は夫の家名を継ぐので王朝が入れ替わります（女王が継承者なら女系婚で自分の家名を継がせる）。
- 幼い王には**摂政**がつきます。野心が強く情けの薄い継承者は王を**暗殺**することがあります。
- **戦争**：野心的な王ほど弱い隣国に宣戦します。兵力は地方の人口と王の統治力、会戦は指揮官の武勇と運で決まり、貴族の男たちも戦死します。
- **反乱**：摂政・狂王・敗戦・広すぎる領土は国を弱くし、諸侯の忠誠を下げます。不満な諸侯の派閥が、簒奪・請求者の擁立・独立（滅んだ国の再興を含む）を起こします。
- 君主は亡くなると治世にちなんだ**あだ名**（大王・狂王・失地王・賢王・美貌王・顎王・短命王…）で呼ばれます。

## 開発

```sh
npm test                          # 遺伝エンジンとシミュレーションのテスト（node:test）
node tools/headless.js 300 demo   # ブラウザなしで 300 年分の年代記を表示（シード demo）
node tools/headless.js 300 demo -q  # 25 年ごとの概要だけ
node tools/metrics.js 8 800        # 8 シード × 800 年で、王国の数・統一された年の割合・最大国のシェア・反乱の勝率を集計
node tools/build.js                 # CSS と JS を埋め込んだ 1 ファイル版を dist/myKingdom.html に出力（サーバーなしで開ける）
node tools/build.js --fragment      # 外枠（<html><head><body>）なし版。Claude の Artifact として公開するときに使う
```

```
index.html, css/style.css
src/
  rng.js        シード付き乱数（isolated-sim と共通）
  genes.js      染色体・遺伝子座・減数分裂・表現型
  pedigree.js   家系と血縁係数・近交係数
  names.js      文化ごとの名前・家名・国名
  map.js        大陸と地方（伯爵領）・公爵領の生成、最初の国境
  feudal.js     封建制（所領・爵位・忠誠・兵の出し渋り・恩賞と没収・派閥の反乱）
  world.js      シミュレーション本体（死・結婚・出生・継承・同盟・戦争・反乱）
  ui/           地図・肖像・人物・家系図・王国・家・統計・図鑑
  main.js       ゲームループと画面
test/           単体テスト
tools/headless.js
```
